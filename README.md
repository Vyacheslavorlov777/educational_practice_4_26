# Учебная практика 4.26

Развитие CRM из [educational_practice_3_26](https://github.com/Vyacheslavorlov777/educational_practice_3_26): история продаж партнеров, ядро алгоритма расчета материалов, его интеграция в интерфейс, модульные тесты и аудит безопасности.

## Структура проекта

- `1) Разработка интерфейса истории реализации продукции/` — новое окно `PartnerHistoryWindow`, переход в него из списка партнеров с передачей `partner_id`, SQL-запрос с `JOIN` (products + sales_history) и таблица «Наименование продукции / Количество (шт.) / Дата продажи».
- `2) Разработка ядра алгоритма расчета материалов/` — метод `calculateMaterialConsumption` (5 входных параметров, коэффициент типа продукции, процент брака, округление вверх, возврат `-1` при некорректных данных вместо исключения) и мок-справочники БД.
- `3) Интеграция метода расчета и комплексное тестирование/` — калькулятор расхода материалов встроен в интерфейс (`MaterialCalculatorWindow`), результат выводится на экран, некорректный ввод обрабатывается без падения приложения.
- `4) Модульное тестирование (Unit Testing) и аудит безопасности/` — 6 unit-тестов (`node:test`) для метода расчета материалов, аудит SQL-запросов на параметризацию (`SECURITY_AUDIT.md`), файловое логирование ошибок (`app.log`).

## Запуск

Каждый этап — отдельный подпроект. Пример запуска:

```bash
cd "4) Модульное тестирование (Unit Testing) и аудит безопасности"
npm start   # приложение на http://localhost:3000
npm test    # unit-тесты метода расчета материалов
```
